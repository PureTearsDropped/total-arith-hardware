
## 【新発見】不確かさを持つと双線形アルゴリズムの選択が自由でなくなる

```
python3 four_complex.py
```

複素代数を2通りの配線で（**素子差し替えのみ・双線形ユニットは無改造**）:

| 配線 | ゲート数 | 三値入力 | ?を1桁 Re/Im | ?を多く Re/Im | 最大 |
|---|---|---|---|---|---|
| 素朴 R=4 | 13,144 | 厳密 | 1.40 / **1.40** | 2.38 / **2.38** | 10.3 |
| ガウス R=3 | 10,432 | 厳密 | 1.40 / **18.14** | 2.38 / **44.48** | **1365** |

両方とも健全（取りこぼし0）、三値入力なら両方とも厳密。しかし `?` が入ると
**ガウスの虚部だけが13〜19倍緩む**。

原因は **区間演算の依存性問題**: `Im = p2 − p0 − p1`、`p2 = (a0+a1)(b0+b1)`。
`p2` の不明と `p0`/`p1` の不明は同じ `a0,a1` 由来なのに、表現が相関を追跡できないので
引いても打ち消せない。実部は両方 `p0 − p1` で同じ式なので締まりも同じ。

⟹ **部分式を再利用するアルゴリズム（カラツバ／ガウス／シュトラッセン）は、積の個数を
減らす代わりに締まりで払う。** 厳密な算術では R が小さいほど良かったのに、不確かさを
持つと逆転しうる（ガウスは21%ゲートが少ないのに虚部の締まりで13倍払う）。
**IMPLS の棚の選択基準が変わる。**

## 桁の意味（両端）

```
先頭（溢れ領域）        末尾（誤差領域）
  0 → 溢れなし           0 → 厳密
 +1 → GE（以上）        +1 → LE（以下）
 −1 → LE（以下）        −1 → GE（以上）
  ? → 符号不明(SUNK)     ? → 両側不明
```

`0` と `?` は上下で同じ意味、`±1` は**逆**（上へは発散・下へは収束するため）。
⟹ **GE/LE/SUNK が桁の値そのものから出る**。特に **SUNK は先頭が `?`**。
三値ではこれを書く場所が無く、`ternary_mark` の敗因の一つだった。

## 検証の作法

オラクルは**機構から独立**にした（`ternary_mark` の失敗の教訓）。`?` を含む語の意味は
「`?` を {−1,0,+1} に置き換えた全具体化の集合」なので、入力を全具体化して真の集合を作り、
出力の語が表す集合に含まれるかを見る。**機構を一切使わないので、機構を変えても基準が
動かない。**
